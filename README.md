## 这是什么

做短视频的人都知道：**内容再好，前 3 秒留不住人，后面全白搭。**

这个工具把「开场钩子」拆成 6 大类、48 条可直接套用的句式模板。每条都标了**为什么有效**（心理学机制），你要做的是把 `{占位符}` 换成自己的内容。

## 六大类

| 类型 | 条数 | 核心机制 |
|---|---|---|
| **悬念反差** | 8 | 制造认知落差，逼观众等答案 |
| **痛点直击** | 8 | 复述观众处境，产生「说的就是我」 |
| **利益诱惑** | 8 | 承诺具体收益，降低划走意愿 |
| **身份代入** | 8 | 圈层认同，建立亲近感和专业性 |
| **冲突剧情** | 8 | 戏剧张力，情绪浓度最高 |
| **数据权威** | 8 | 数字和实测背书，增强可信度 |

## 怎么用

1. 打开后按分类浏览，或点「随机抽一条」找灵感
2. 看中哪条，点右边「复制」
3. 把 `{占位符}` 换成你自己的内容

### 举个例

**模板**：`我花了 {金额} 块，结果 {意外结果}。`

**填完**：`我花了 3000 块买了台咖啡机，结果发现楼下便利店 8 块钱的更好喝。`

**为什么有效**：先抛数字（具体可信）→ 再给反常识结果（认知落差）→ 观众想知道"到底怎么回事"，自然看下去。

## 使用原则

**钩子只是入场券，不是全部。** 三条建议：

1. **别硬套** —— 模板是骨架，得填你自己的血肉。硬套会显得假
2. **前 3 秒必须给信息** —— 钩子之后立刻要有实质内容，否则掉得更快
3. **同一条别重复用** —— 观众会疲劳，轮着来

## 热门平台的差异

| 平台 | 钩子偏好 |
|---|---|
| 抖音 / 快手 | 冲突剧情、悬念反差，情绪越浓越好 |
| 视频号 | 身份代入、痛点直击，偏熟人社交 |
| 小红书 | 利益诱惑、数据权威，「保姆级」更吃香 |
| B 站 | 数据权威、悬念反差，可以长一点 |

## 自定义

打开 `index.html`，找到 `DATA` 对象：

```js
var DATA = {
  '悬念反差': [
    { t: '我花了 {金额} 块，结果 {意外结果}。', w: '先给数字和结果，制造认知落差' },
    // 在这里加你的模板
  ],
  // 加新分类
};
```

`t` 是模板文本，`w` 是「为什么有效」的说明。
